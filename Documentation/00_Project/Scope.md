# Scope

## Zakres projektu

Dokument definiuje funkcjonalności objęte implementacją.

# Zakres podstawowy

## Rozgrywka

- utworzenie postaci,
- wybór klasy,
- eksploracja lochu,
- walka turowa,
- przejście do kolejnych etapów.

## Postać

- statystyki,
- doświadczenie,
- poziomy,
- rozwój.

## Walka

- atak,
- obrona,
- użycie przedmiotów,
- efekty statusowe.


## Dungeon

- generowany układ pomieszczeń,
- przeciwnicy,
- boss.


## Ekwipunek

- przedmioty,
- rarity,
- zarządzanie wyposażeniem.


## Ekonomia

- złoto,
- sklep,
- handel.


## System zapisu

- zapis stanu,
- odczyt.


# Zakres rozszerzony

Elementy realizowane w zależności od dostępnego czasu.

- questy,
- statystyki sesji,
- liczniki śmierci,
- dodatkowe typy przeciwników,
- osiągnięcia,
- dodatkowe wydarzenia w lochu.


# Elementy poza zakresem

Nie będą realizowane:

- multiplayer,
- sieć,
- proceduralne generowanie assetów,
- crafting,
- modding,
- edytor map,
- voice acting,
- system ekonomii online,
- zaawansowana AI.


# Ograniczenia

- krótki czas realizacji,
- wykorzystanie gotowych assetów,
- nacisk na architekturę i testowalność.
