Oddzielenie walki jako osobnej sceny

# Kontekst

Gra wykorzystuje turowy system walki oraz eksplorację świata. GDD zakłada oddzielny przebieg walki i ładowanie sceny walki.

Należało zdecydować czy walka będzie:

- częścią eksploracji,
- osobnym stanem.

# Decyzja

Walka realizowana będzie jako oddzielna scena.

Przepływ:

1. SafeHouse
2. Dungeon
3. Combat
4. Reward
5. Dungeon

Po rozpoczęciu walki:

- zapisujemy stan świata,
- uruchamiamy Combat Session,
- po zakończeniu aktualizujemy stan.

# Uzasadnienie

Korzyści:

- prostszy model domenowy,
- mniejsza liczba stanów,
- łatwiejsze testowanie.

# Konsekwencje

Pozytywne:

- prostszy przepływ,
- niezależny Combat.

Negatywne:

- konieczność przełączania scen.

# Alternatywy

Walka w tej samej scenie.

Odrzucono z powodu:

- większej złożoności.
